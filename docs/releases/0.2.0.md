# Ernie Preview 0.2.0

A macOS Apple Silicon preview of Ernie, based on main at 874029d, with an amber app icon and the Ernie Preview application name.

## Included

- Agent creation and model selection improvements
- Persisted appearance settings and scoped customization entry points
- Subagent results and parent links in conversation activity
- App-history checkpoints and recovery
- A reusable unsigned preview build and publication command

## Installation

Download the arm64 ZIP, verify it against SHA256SUMS, extract it, and move Ernie Preview.app to Applications. This archive has an ad-hoc signature only. It is not Developer ID signed or notarized by Apple. macOS may require explicit approval under System Settings > Privacy & Security after the first launch attempt. Do not disable Gatekeeper globally.

First startup requires network access to install the bundled source dependencies. Preview source and history use ~/.zenbu/apps/ernie-preview and ~/.ernie-preview/app-history. The Prime Agent daemon remains shared with other Ernie clients.

## Preview limitations

This is a GitHub prerelease and is not the latest stable release. The integrated browser panel, interaction sounds, and experimental shadcn-cssinjs work are not included in this candidate. Full first-install and prior-version upgrade validation are not claimed unless recorded in the release verification section.
