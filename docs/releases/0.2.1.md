# Ernie 0.2.1

Model menus appear above their settings panel. Conversation participants stay in one horizontally scrolling header row, and shared disclosure controls replace default browser markers. Lint guards enforce the disclosure boundary before commits and releases.

This release consolidates the current composer, folder controls, native session handling, and bundled Ernie skills. The website links to this version using the application package version.

Ernie uses its normal name and artwork. The recovery host no longer competes with the editable app for the single-instance lock. Opening Ernie again focuses the app while recovery remains available from its menu. The recovery host uses a separate Chromium profile so the application cannot replace its singleton socket.

Ernie connects to an existing Prime Agent daemon. It does not start or stop a daemon. The client SDK remains bundled in the source dependencies. A custom endpoint can be selected with `ERNIE_PRIME_AGENT_SOCKET`.

The bundled installer accepts the upstream Prime Agent package aliases with a frozen lockfile, including when the pnpm store already contains those packages.

The Apple Silicon ZIP uses an ad-hoc signature without Developer ID or notarization. macOS may require approval in System Settings > Privacy & Security after the first launch attempt.

The v0.2.0 Preview release remains unchanged. This version uses the normal Ernie installation and history directories.
