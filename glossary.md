# Ernie glossary

## Draft session

A session that exists but has not received its first user message.

## New-session state

The initial view of a draft session before the conversation begins.

## Draft hero

The new-session composition that places the conversation starter directly above the composer.

## Conversation starter

The prompt that invites the user to send the first message in a draft session.

## Empty transcript

A conversation transcript that contains no messages. This names the message area, not the whole new-session state.

## Session header

The region that identifies the current session and its workspace.

## Model picker

The composer control that searches Prime Agent's model catalog and selects the model for a session.
