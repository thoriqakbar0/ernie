ernie

an interface that adapts to your work.

Ernie gives durable Prime Agent sessions a repository-aware macOS home. Work remains attached to its repository, worktree, tools, and child Agents instead of dissolving into one transcript.

work stays where it belongs.

Ernie keeps the desktop shell calm while Prime Agent remains the authority for execution and session history.

repository-aware

sessions stay grouped with repositories and linked Git worktrees, so their working context remains visible.

durable by default

Prime Agent owns the session. Ernie can reconnect, restore, and continue without becoming a second source of truth.

bounded and inspectable

typed IPC, local UI controls, and lifecycle-managed plugins keep important boundaries explicit.

the first mac build is real.

v0.1.0 packages the working Electron application, its renderer, and the installed Prime Agent runtime graph for Apple silicon.

this build is for private testing. public distribution follows after Developer ID signing and Apple notarization.
