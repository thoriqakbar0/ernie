v0.1.0 · macOS for Apple silicon · private alpha

the first mac build

v0.1.0 packages the working Ernie desktop app for Apple silicon. it connects to Prime Agent, preserves sessions by repository, and keeps the next action close to the work.

this first build is a private, ad-hoc signed alpha. public download comes after Developer ID signing and Apple notarization.

the interface should follow the task.

chat is one useful surface, not the final shape of every kind of work. Ernie is an experiment in interfaces that preserve the structure an agent discovers.
