ernie

a fixed workspace for studying what agent-shaped software requires.

Ernie is a macOS artifact for testing a specific question: how can an agent influence the interface without controlling the whole application? v0.1.0 tests narrow UI controls and plugin lifecycles inside a fixed shell.

each session stays with its repository.

Prime Agent owns execution and durable session state. Ernie presents that state and sends typed requests through its daemon adapter.

repository and worktree context

each session stays grouped with the repository or linked Git worktree where it runs.

Prime Agent owns the session

Ernie reads and updates sessions through Prime Agent. It does not store a competing copy of session history.

local controls have limits

the UI CLI can focus the window, select a light or dark theme, and change the sidebar. It cannot control sessions or Git.

v0.1.0 runs on Apple silicon.

v0.1.0 packages the working Electron application, its renderer, and the installed Prime Agent runtime graph for Apple silicon.

the public ZIP uses an ad-hoc signature and is not notarized by Apple. macOS can block the first launch. A standard macOS release would require Developer ID signing and Apple notarization; no date is promised.

task-shaped interfaces are still a research direction.

v0.1.0 uses a fixed desktop shell. Ernie is a learning lab for whether future, trusted surfaces could preserve the structure an agent discovers without giving it arbitrary control of the interface.
